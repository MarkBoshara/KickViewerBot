## 🚀 Key Features & Capabilities

### ⚡ Unlimited Concurrent Viewers
* **Scalable Engine:** Simulates from 100 to 5,000+ live stream viewers seamlessly.
* **No Artificial Throttling:** Zero capping on viewer numbers or active connections.
* **Asynchronous Workers:** Powered by non-blocking `asyncio` WebSocket threads for maximum speed.

### 🌐 Universal Proxy Engine
* **Supports All Protocols:** Compatible with `HTTP`, `HTTPS`, `SOCKS4`, and `SOCKS5` proxies.
* **All Format Parsing:** Automatically normalizes `IP:Port`, `IP:Port:User:Pass`, `User:Pass:IP:Port`, and `User:Pass@IP:Port`.
* **Multi-Encoding Support:** Seamlessly reads text files encoded in `UTF-8`, `Latin-1`, `CP1252`, `GBK`, or direct paste input.
* **Proxyless Mode:** Optional direct connection support for rapid testing.

### 📺 Live Kick.com Stream Integration
* **Official WebSocket Handshake:** Direct handshake connection to Kick WebSocket servers (`websockets.kick.com`).
* **Real-time Live Viewer Tracker:** Tracks official Kick stream viewer counts in real time.
* **Automatic Channel Resolution:** Instant username-to-channel-ID resolution with Cloudflare bypass headers.

### 🎨 Futuristic Cyber Dark Interface
* **Sleek Cyber Theme:** Designed with obsidian dark background, neon emerald accents, and glassmorphic cards.
* **Live Status Indicator:** Pulsing online/offline status dot (`🟢 ONLINE RUNNING`).
* **Interactive Dashboard:** Presets for fast viewer selection (`100`, `500`, `1000`, `2500`, `5000`), live terminal logs, and session uptime counter.

### 🛡️ 24/7 Server Stability
* **Automated Error Logging:** Built-in exception logger writes unhandled errors directly to `error_log.txt`.
* **Windows Server Compatible:** Tested and optimized for continuous 24/7 uptime on Windows Server 2016/2019/2022.
